Interpretation:
  - If 'delta_excl_per100' or 'delta_allcaps_per100' has large +β for VADER but ~0 for TB,
    that supports H2 (VADER weights punctuation + caps; OPs have more).
  - If 'delta_firstperson_per100' has large +β for VADER, supports H1.
  - If 'delta_negation_per100' has large effect, suggests OP/reply differ in negation density.
  - If multiple features have small β and R² is low (<0.05), the directional split is NOT
    explained by these surface features — it's deeper instrument-property difference.
