CAVEATS
--------------------------------------------------------------------------------
- PSLF eligibility is heuristic: keyword-based on institution name only.
  Misclassifies in both directions (e.g., some 'University' programs
  are private; some 'community' nonprofits qualify).
- ~50% of institutions are 'ambiguous' (no clear marker either way).
  Manual classification of ambiguous would refine the test.
- Hostile-program n is small (~23 institutions); pediatric estimates
  in particular are based on n<10 program-years.
- Selection bias: for-profit chains may bid lower-quality applicants;
  fill rate proxies but does not isolate PSLF as the mechanism.
- NRMP usage compliance: per the 2021-2025 PDF copyright notice, no
  AI/ML model training; for publication, request explicit NRMP
  permission via datarequest@nrmp.org.
