## Why this matters now

All current PSLF papers (P3, P5, P6) operate at the **institution-year level** because that's the public-data resolution available. The substantive limitation is that institution-level classification cannot identify:
- Actual borrower-level PSLF participation rates within each program
- Borrower-level loan-balance trajectories
- Borrower-level discharge outcomes
- Cross-walking individual loan data to specialty + program + outcome

These analyses require the **National Student Loan Data System (NSLDS)** — the federal database maintained by the U.S. Department of Education containing every federal student loan record. NSLDS data is NOT publicly available; access requires a Data User Agreement (DUA) with the Department of Education.

**Typical DUA timeline: 6-12 months from application to data delivery.** Starting NOW positions the user to have NSLDS data available during PGY-1 year (2028-2029) for a follow-up paper that would be the strongest single contribution from this entire research program.

## DUA application requirements (verify current at https://nsldsfap.ed.gov/)

### Required documents

- [ ] **Research proposal** (5-10 pages) describing:
  - Specific research questions
  - Data elements requested (loan-level vs aggregate; specific NSLDS variables)
  - Statistical methods
  - Expected publications and dissemination
  - Public-interest justification
- [ ] **IRB approval** from the user's institution OR formal IRB-exempt determination letter
- [ ] **Data security plan** documenting:
  - Where data will be stored (encrypted institution server / approved cloud)
  - Access controls (named individuals only)
  - Data destruction protocol after publication
  - Compliance with FERPA + Privacy Act requirements
- [ ] **Signed DUA agreement** with terms of use, prohibitions on re-identification, publication restrictions
- [ ] **Institutional sponsor letter** from a senior faculty member (likely the PSLF-project senior PI or research-year NS mentor) acknowledging institutional support and oversight
- [ ] **Curriculum vitae** for the user + senior sponsor

### Application process (typical sequence)

1. **Identify the right DUA pathway** — there are two main routes:
   - Direct NSLDS DUA via Federal Student Aid (most restrictive; for ED-affiliated researchers)
   - PSLF-specific research data access via the SBPC/CFPB pipeline (newer; less established)
   - Restricted-use data via NCES (National Center for Education Statistics) — easier but less granular
2. **Pre-application conversation** — email NSLDS data services to discuss the research question + scope
3. **Submit application package** with all required documents
4. **Review period (typically 3-6 months)** — Federal Student Aid reviews; may request clarifications
5. **DUA negotiation + signing** — final terms; data security audit
6. **Data delivery (typically 1-3 months after signing)** — encrypted file transfer
7. **Analysis + publication** — typically 6-12 months
8. **Data destruction at study end**

## Cost / effort estimate

- **Application package preparation:** ~40-80 hours (1-2 weeks of focused effort)
- **Institutional fees:** typically $0-$500 (NSLDS data access fees are minimal for academic researchers; some institutions have their own IRB fees)
- **DUA review fees:** typically $0 from DOE
- **Data storage / compute:** likely negligible if using institution server; AWS encrypted storage if needed (~$50-100/month)
- **Total $$ cost:** under $1,000 typical
